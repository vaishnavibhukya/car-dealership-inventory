# AI Prompts Used

This file documents the AI prompts and assistance used during the development of the Car Dealership Inventory Management application.

## 1. Project Planning

- Help me design a full-stack car dealership inventory management application.
- Suggest a suitable project structure for the frontend, backend, database, and testing.
- Help identify the main features required for a dealership inventory management system.

## 2. Backend Development

- Help implement the backend using FastAPI.
- Create API endpoints for managing cars in the dealership inventory.
- Implement functionality to add, update, delete, purchase, and restock vehicles.
- Help implement user registration and login functionality.
- Help organize the FastAPI application using models, schemas, routes, and database modules.

## 3. Database

- Help design database models for users, cars, and sales.
- Help connect the FastAPI application to SQLite.
- Help implement database operations for vehicle inventory management.

## 4. Frontend Development

- Help create a React frontend for the car dealership inventory management system.
- Create pages for Home, Registration, Login, Inventory, Add Vehicle, and Dashboard.
- Help design a modern and responsive dealership management interface.
- Help connect the React frontend with the FastAPI backend.

## 5. Dashboard and Inventory

- Help implement an inventory dashboard showing total vehicles, available vehicles, sold vehicles, and total inventory value.
- Help implement vehicle search and inventory management.
- Help implement actions such as Edit, Delete, Purchase, and Restock.

## 6. Testing

- Help create pytest test cases for the backend API.
- Help identify and fix failing tests.
- Help verify that the backend API functionality works correctly.
- Help achieve a passing backend test suite.

## 7. Debugging

- Help troubleshoot errors in the FastAPI backend.
- Help debug frontend and backend integration issues.
- Explain errors and suggest fixes while developing the application.
- Help resolve Git and project setup issues.

## 8. Documentation

- Help create and organize the project README.
- Help document the project structure, features, setup instructions, API functionality, and testing.
- Help add screenshots of the completed application to the README.

## 9. Git and GitHub

- Help troubleshoot Git errors and safely commit project changes.
- Help organize project files before submitting the GitHub repository.
- Help verify that the completed project, screenshots, documentation, and tests are committed and pushed to GitHub.
